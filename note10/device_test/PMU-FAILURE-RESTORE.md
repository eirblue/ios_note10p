# Scoped CPU-PM failed-entry PMU restoration

This default-off guard addresses the pinned ARM PMU notifier's failed-entry path. Immediately before stopping events, it captures only used slots whose events were running. On the paired failed-entry notification, it consumes the snapshot, checks all captured slots and restarts those events before the original global PMU start. Events already stopped remain stopped, including those without the up-to-date flag. Successful exit retains the original reset, setup and global-start sequence and only clears the saved identities. Invalid or unmatched snapshots do not suppress the original notification or start arbitrary captured slots.

The supported scope is the pinned CPU-PM contract: the affected CPU enters with IRQs disabled, failed-entry dispatch is synchronous on that CPU, and ordinary perf event removal serializes with that CPU and clears its PMU slot before release. Pointer equality alone cannot establish object lifetime or detect address reuse. The scope excludes direct slot manipulation outside supported perf APIs, reentrant CPU-PM, IRQ enabling, NMI mutation, CPU hotplug and PMU teardown during this interval. The pinned schedutil callback can wait for a timer; its completion and deadlock freedom require separate review before any actual CPU-PM use. The guard explicitly depends on the previous CPU-PM failure guard, which initializes the notifier call count; the pinned original does not.

PC native models execute the prepared notifier and the original PMU stop/start bodies with synthetic hardware and perf operations. They test stopped and running mixtures, removal and identity mismatch, IRQ state, duplicate and unmatched notifications, per-CPU and per-PMU isolation, all slots and the prepared notifier chain's failure dispatch. These are model results, not hardware fault injection or proof of exact counter values or timing. The existing physical diagnostic does not call CPU-PM and retains its 37 evaluations; this guard does not prove hardware restoration, global DMA shutdown, XNU execution or iOS boot.
